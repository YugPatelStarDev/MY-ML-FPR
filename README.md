🛠️ CUSTOMIZATION

Want to create your own version?

Change the CSS variables:

:root {
  --cyan: #00f5ff;
  --purple: #9b5cff;
  --pink: #ff3cac;
}


Try replacing them with your own colors:

:root {
  --cyan: #00ff88;
  --purple: #ff00ff;
  --pink: #ff6600;
}
