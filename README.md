⚡ MY-ML-FPR

A futuristic, interactive web experience built with HTML, CSS & JavaScript — all in a single file.






🌌 About

MY-ML-FPR is a lightweight futuristic dashboard designed to showcase what can be created with just the three core web technologies:

HTML + CSS + JavaScript

No frameworks.
No external libraries.
No complicated setup.

Just one file, some creativity, and a little bit of JavaScript magic. ⚡

The project features a neon-inspired interface with glassmorphism cards, animated gradients, interactive controls, live system time, animated statistics, and a particle background.

✨ Features
🌌 Futuristic neon UI
💎 Glassmorphism design
🎨 Animated gradient typography
⚡ Interactive JavaScript controls
☀️ Light / Dark theme switcher
✨ Random accent-color generator
🚀 Interactive launch button
📊 Animated percentage counters

🛠️ Customization

Want to make it your own?

Try changing the CSS variables:

:root {
  --cyan: #00f5ff;
  --purple: #9b5cff;
  --pink: #ff3cac;
}


You can create completely different visual themes by changing these colors.

You can also modify:

Dashboard statistics
Hero text
Button actions
Particle behavior
Animations
Background effects
